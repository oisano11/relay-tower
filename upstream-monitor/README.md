# 🗼 中转塔台 (Relay Tower) (Upstream Monitor & Switcher Console)

专为 AI 中转站运营设计的上游通道智能监控与调度中枢。

## 🌟 核心功能

1. **中控台随时显示上游倍率**
   - 实时大盘展示各上游渠道当前成本倍率（如 `0.65x`, `0.85x`, `1.10x`）。
   - 自动定时探活与测速，实时展示上游网络延迟（ms）及连通性状态。
   - 支持主流 New-API / One-API `/api/pricing` 价格探针，支持随时添加、编辑和删除上游渠道。

2. **上游倍率调整弹窗提醒**
   - 实时差分算法感知上游调价动作（上涨或下调）。
   - 居中弹出强警示度模态弹窗，展示 `变动渠道`、`原倍率 -> 新倍率` 及 `涨跌百分比`。
   - 结合 Web Audio 合成声效警报。
   - **高危涨价预警**：当变价通道是当前主力出海通道时，触发红色警示，并提供“一键切换到更低倍率备选通道”快捷操作。
   - 完整记录历次调价审计流水（Audit Log）。

3. **一键切换使用那条上游通道**
   - 中控台所有卡片及顶部快捷下拉框均支持“一键设为主用”。
   - 内置智能反向代理网关（Smart Proxy Gateway）：
     - 开放统一 API 入口：`http://localhost:3300/v1`
     - 客户端（如 CC Switch、Codex、Chatbox 或中转站前端）配置此入口后，在中控台一键切换通道，后续请求**零停机、毫秒级即时切换**至新上游。
   - 自带控制台内嵌【智能代理分流验证测试器】，可随时发起真实调用检验分流效果。

4. **✈️ Telegram 机器人推送与移动端远程中控 (Telegram Bot Remote Console)**
   - **离机即时推送**：
     - 上游进货倍率变动实时告警（含涨跌幅度与变价渠道）。
     - **主力涨价高危警报**：当正在出海的主力通道被上游涨价时，Telegram 立即报警并在消息底部附带低价备选线路的**一键切换按钮**。
     - **自动切线报告**：当系统触发首字超时 (TTFT) 熔断或宕机自动切线时，推报警情并报告新旧倍率与延迟对比。
   - **手机端双向交互与一键切线**：
     - `/status`：查看当前主力通道、进货倍率、销售毛利率、延迟与自动切线状态。
     - `/switch`：弹出所有上游通道的 **Inline Keyboard 点击交互按钮**，在手机上点击任意渠道秒级完成调度切线。
     - `/auto`：在手机上一键开关自动切线保护，或切换成本优先/极速优先策略。
     - `/rates`：输出所有上游渠道进货倍率从低到高天梯榜。
     - `/check`：立即发起全量上游价格探针与测速巡检。
   - **安全与长轮询架构**：
     - 采用 Long Polling 长轮询，内网/Docker/VPS 免公网 IP、免域名与 SSL 证书即开即用。
     - 首发 `/start` 自动无缝绑定超级管理员，白名单鉴权杜绝未授权篡改。

## 🚀 启动方式

```bash
cd upstream-monitor
node server.js
```
或者运行脚本：
```bash
./scripts/start.sh
```

打开浏览器访问：`http://localhost:3300`
